# v0.5.8 配布の検証

- 公開masterの `2160e6e` から作成した。公開済みのv0.5.7タグと配布物を保持し、アプリ・製品定義・インストーラーの版を更新した。
- SQLiteとZIPの指摘に対応するため、`libsqlite3-sys` 0.39.1と`zip` 9.8.1を採用した。再監査で両依存の指摘は解消した。残る`paste`はコンパイル時の依存に対する保守終了通知で、`rustix`は配布対象のWindows x64向け依存グラフに含まれない。
- 実入力の初回試験で標準ラベルのコピーに失敗した。UI AutomationのText要素がテキスト範囲を公開しない場合、その要素名を取得するようにした。試験は既存クリップボードデータがあるときに中止し、試験終了時は試験プロセスが置いたデータを消去する。
- Windows x64のReleaseビルドが成功し、テスト110件が合格した。既存の明示除外は3件。ZIPの非圧縮・Deflate項目の展開と履歴の記録・読込も合格した。
- 修正後の実入力試験で、F8押下中の枠、解放コピー、空白で離した際の内容保持、左ドラッグで囲んだ複数行のコピー、試験用クリップボードの消去を確認した。
- 配布版を隔離設定で起動し、初回案内と設定画面を確認した。設定画面で、プレビューキーの下にテキストキャプチャキーがあり、初期値がF8と表示されることを確認した。管理CLIによる起動と終了、従来の設定、移行前設定と履歴ファイルのSHA-256を確認した。
- ビルド端末のパスを置換した実行ファイルを使用した。セットアップと本体の署名・タイムスタンプ、Microsoft公式配布物とのDirectMLハッシュ一致、配布物の展開と内容比較を確認した。配布元の証明書は自己署名。
- 生ログ・試験用の設定・設定画面の録画は `logs/` に保存した。
