## 未実装

### 1. 定額プランを利用するLLM CLI実行機能

- 既存のLLM APIと同様に、CLIを呼び出してOCR・翻訳・解説を実行できるようにする。
- 対象CLIは以下の5種類とする。
  - Codex CLI
  - Claude CLI
  - GitHub Copilot CLI
  - Gemini CLI
  - Kimi CLI（Kimi K3）
- API従量課金ではなく、各CLIへログイン済みの定額プラン／クレジットを利用する。

## 質問と回答（QA）

実装前に確認した論点と決定。日付: 2026-08-10

| # | 質問 | 回答 | 関係する要求 |
| :--- | :--- | :--- | :--- |
| 1 | CLIを既存LLMプロファイルへ統合するか | 既存LLMプロファイルへ統合し、OCR・翻訳・解説チップからAPI方式と同様に選択できるようにする | §1 |
| 2 | CLIの導入・ログインまでアプリで自動化するか | PATHからの自動検出と実行ファイルの手動指定、状態確認、セットアップ案内までとし、インストール・ログイン自体は自動化しない | §1 |
| 3 | CLIごとのモデル指定をどう扱うか | モデル欄は任意指定とし、空欄ならCLIの既定モデルを使用する。Kimi CLIだけは既定値を `k3` とする | §1 |
| 4 | CLIへ与える権限 | 一時作業フォルダ内の入力・画像の読み取りだけを基本とし、ファイル編集・シェル実行・Web検索等は可能な限り無効化する | §1 |
| 5 | タイムアウトと失敗時のフォールバック | タイムアウトは120秒。未導入・未ログイン・画像非対応・上限到達等は明示的なエラーとし、別エンジンへ自動で切り替えない | §1 |
| 6 | トークン数の記録 | CLI出力から取得できる場合のみ記録し、取得不能なCLIは不明として扱う | §1 |
| 7 | 「定額プラン内」の扱い | ログイン済みCLIのサブスクリプション／クレジットを利用するが、各社の利用上限や追加課金設定には従い、完全な使い放題は保証しない | §1 |
