## 実装済

### 1. 定額プランを利用するLLM CLI実行機能

- 既存のLLM APIと同様に、CLIを呼び出してOCR・翻訳・解説を実行できるようにする。
- 対象CLIは以下の5種類とする。
  - Codex CLI
  - Claude CLI
  - GitHub Copilot CLI
  - Gemini CLI
  - Kimi Code CLI
- API従量課金ではなく、各CLIへログイン済みの定額プラン／クレジットを利用する。

実装結果: [`v0.5.6-imp.md`](./v0.5.6-imp.md) — 完了（2026-08-10）

### 2. 利用可能モデルの選択UI

- LLM APIとLLM CLIのモデル名設定で、実際に利用可能なモデルを調べてプルダウンから選択できるようにする。
- プルダウン化後も、任意のモデル名を直接入力できるようにする。
- CLIプロファイルの既定モデルには、各CLIで利用できる軽量モデルを設定する。
- 選択中の種別で使用しない入力欄はグレーアウトする。

実装結果: [`v0.5.6-imp.md`](./v0.5.6-imp.md) — 実機確認済み（2026-08-11）

### 3. ホットキーと名称の追加修正

- Kimiの名称を「Kimi Code CLI」に統一する。
- 選択範囲ホットキーから範囲選択を重ねて開始できないようにする。
- 範囲選択画面とピン留めオーバーレイをESCで確実に閉じられるようにする。
- プレビューキーの既定値を「なし」にして、LCtrl検知を既定で無効にする。

実装結果: [`v0.5.6-imp.md`](./v0.5.6-imp.md) — 実機確認済み（2026-08-11）

### 4. アプリ別リスト間の移動

- アプリ別の動作設定画面で、OCR優先アプリリストと実行しないアプリリストを相互に移動したい。リストボックスの間に二つの矢印付き「移動」ボタンを置いて

実装結果: [`v0.5.6-imp.md`](./v0.5.6-imp.md) — 自動テスト済み（2026-08-11）

### 5. BossGuard

- 設定画面のシステム設定のグループボックスの中に、BossGuardチェックを追加して、チェックピンをオンにしたら、タイトルバー、設定画面、オーバーレイ画面のアプリ名や開発者名が空白文字に置き換わり見えないようにしてください。

実装結果: [`v0.5.6-imp.md`](./v0.5.6-imp.md) — 実機確認済み（2026-08-11）

### 6. リッチクリップボードのMarkdown取込

- コピー中の内容がリッチテキストの場合は、実際に格納するテキストは Markdown 形式に変換して記録する。プレーンテキストでも原文の再現性を高くすること。

実装結果: [`v0.5.6-imp.md`](./v0.5.6-imp.md) — 自動テスト済み（2026-08-11）

| 1 | CLIを既存LLMプロファイルへ統合するか        | 既存LLMプロファイルへ統合し、OCR・翻訳・解説チップからAPI方式と同様に選択できるようにする                                     | §1          |
| 2 | CLIの導入・ログインまでアプリで自動化するか | PATHからの自動検出と実行ファイルの手動指定、状態確認、セットアップ案内までとし、インストール・ログイン自体は自動化しない      | §1          |
| 3 | CLIごとのモデル指定をどう扱うか             | 自由入力と取得候補からの選択を併用する。追加要望によりCLIは軽量既定値を持ち、Kimi Code CLIは`k3-256k`とする                 | §1, §2      |
| 4 | CLIへ与える権限                             | 一時作業フォルダ内の入力・画像の読み取りだけを基本とし、ファイル編集・シェル実行・Web検索等は可能な限り無効化する             | §1          |
| 5 | タイムアウトと失敗時のフォールバック        | タイムアウトは120秒。未導入・未ログイン・画像非対応・上限到達等は明示的なエラーとし、別エンジンへ自動で切り替えない           | §1          |
| 6 | トークン数の記録                            | CLI出力から取得できる場合のみ記録し、取得不能なCLIは不明として扱う                                                            | §1          |
| 7 | 「定額プラン内」の扱い                      | ログイン済みCLIのサブスクリプション／クレジットを利用するが、各社の利用上限や追加課金設定には従い、完全な使い放題は保証しない | §1          |
