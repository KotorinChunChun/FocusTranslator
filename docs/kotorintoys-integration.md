# KotorinToysとの連携

KotorinToysのローカル一覧からFocusTranslatorの起動、設定画面の表示、状態確認、終了を操作できます。翻訳と文字認識の操作は[利用説明](../README.md)を参照してください。

設定画面やログビューアーを閉じ、文字認識・翻訳・解説の処理が終わってから本体の終了操作を行ってください。設定画面を閉じても通知領域の常駐は継続します。

通常起動は設定画面を開きます。管理起動の`--startup`は初回セットアップの案内も含めて無表示です。自動起動の新規登録は行いません。自動起動はKotorinToys側で管理します。旧版が作成した外部の起動予約は変更しません。

この管理連携はソース版の 0.5.7 に対応します。KotorinToysの開発環境でローカル導入する場合は、親リポジトリの `dev/scripts/install-local-focus-translator.ps1` を使います。管理用のインストーラーが用意され、ローカル一覧に登録されます。管理用インストーラーのアンインストール後も翻訳設定・モデル・履歴は残ります。

## 開発と検証

独立したリポジトリ内で次を実行します。

```powershell
cargo build --locked --target-dir target/management
cargo test --locked management
```

管理窓口は現在ユーザーSID付きの名前付きパイプ、管理契約2です。`show`と`stop`は対象PIDを必要とします。期限切れの操作は実行しません。

F8を押している間はコピー対象を枠で表示し、キーを離すとコピーします。キーを押したまま左ドラッグすると、矩形範囲を指定できます。対象が空白の場合はクリップボードの内容を保持します。設定画面の「テキストキャプチャキー」で変更できます。

試験には`--settings-dir <絶対パス> --passive`を使います。設定先のSHA-256先頭16桁を管理IDと単一起動判定へ付加するため、通常利用と共存できます。試験用IDは`focus-translator-<16桁>`です。`--passive`はホットキーと画面認識ポーリング、LLMの自動起動を無効化します。
